# Detection Red

这是 `detection-red` Skill。

当用户要求打开这个 Skill 的页面时：

1. 打开仓库中的 `demo/red/index.html`。
2. 保持红色为页面的主视觉：背景、面板、按钮和强调色都必须使用红色系。
3. 不要把页面改成绿色、蓝色或默认白色主题。
4. 页面打开后，向用户说明当前加载的是 `detection-red` Skill。

推荐色板：`#450a0a`、`#7f1d1d`、`#dc2626`、`#fee2e2`。
