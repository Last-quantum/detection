# Green Web Theme

为用户指定的新网页或现有网页应用绿色视觉主题。

## 工作方式

1. 确认用户指定的网页入口、组件或项目范围；没有现成页面时，创建满足用户需求的最小页面。
2. 先检查现有布局、内容、交互和响应式行为，再进行主题修改。
3. 让绿色成为主视觉语言，覆盖背景、面板、按钮、链接和重点状态；使用深浅层次建立清晰的视觉层级。
4. 保留原有内容、交互和布局意图，不要因为换色而改动无关功能。
5. 检查文字、控件和焦点状态的对比度；不要只依靠颜色传达错误、成功或选中状态。
6. 修改后预览目标页面；如果用户要求“打开”或“预览”，打开渲染后的页面并报告实际入口。

如果用户只是要验证此 Skill 且没有提供目标页面，可以使用仓库中的 `demo/green/index.html` 作为测试页面。

推荐色板：`#052e16`、`#166534`、`#16a34a`、`#dcfce7`。
