# Detection Green

这是 `detection-green` Skill。

当用户要求打开这个 Skill 的页面时：

1. 打开仓库中的 `demo/green/index.html`。
2. 保持绿色为页面的主视觉：背景、面板、按钮和强调色都必须使用绿色系。
3. 不要把页面改成红色、蓝色或默认白色主题。
4. 页面打开后，向用户说明当前加载的是 `detection-green` Skill。

推荐色板：`#052e16`、`#166534`、`#16a34a`、`#dcfce7`。
